## 판정 기술
- WJazzD는 화성 조건 학습의 쌍 자료로 쓸 수 있는 형태를 갖췄다
  - 코드 라벨: 대응 86.0% + 손실 대응 8.6%
  - 박 트랙과 박 주석이 있다
  - 단선율이 깨끗하다
  - 곡 단위 분할이 가능하다
  - v2 표현 없음 층은 약 0.5–0.6%다
- 한계
  - 피아노 6솔로뿐인 관악 단선율이다. 피아노 양손이나 티그랑 스타일의 근거가 아니다
  - sus·감3화음·증3화음 등 대응 없는 코드가 4.1%다
  - 이른 음의 코드 부착 기준(2.3%)을 정해야 한다
  - 솔로의 끝은 대부분 녹음에서 잘라낸 끝(`crop_end`)으로 봐야 한다(미확인)
- 학습 자격: 라이선스 근거(ODbL / DbCL)는 확인했다. 분할 규칙과 코드 부착 기준이 정해지기 전에는 `training` 자격을 켜지 않는다. 학습 단위는 아스트라와 정한다
