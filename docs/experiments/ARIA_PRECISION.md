# Aria 가중치 정밀도별 토큰당 생성 시간과 출력 분포 차이 (사전 등록)

작성 2026-10-18 17시대 KST. 이슈 #1811. 학습, 다운로드, 실시간 재실행, 청취 없음. `quality_claimed: false`.

## 1. 질문

- Aria 가중치를 bf16, 8비트, 4비트로 바꿀 때 현행 float32 대비 토큰당 생성 시간과 다음 토큰 분포 차이

## 2. 배경

- #1807 재실행 A: 블록 마감 여유 최소 35 ms, 중앙값 151 ms. 블록 4 suffix 준비부터 지평 도달까지 273.5 ms
  - 정정(결과 기록 시): 처음 쓴 "27토큰, 토큰당 약 10 ms"는 잘못 계산한 값. 블록 행 `tokens`는 지평 도달 뒤 추측 생성분까지 센 샘플 수라 273.5 ms 구간의 토큰 수가 아님
- #1797 블록 4: 마감 초과, 지평까지 생성 구간이 대부분(토큰 약 50개는 추정)
- #1809: 원하는 릭의 2박 창 최대 11음. 밀도 상한만으로 마감 여유 확보 여부 미확인
- 현행 실시간 경로(`lh_kv_reuse.load_mlx`, `rt_producer.py`): 가중치 float32(2.63 GB, 6.59억 파라미터), KV 캐시 float32
- Aria 공식 MLX 데모(`demo/demo_mlx.py`): `DTYPE = mx.bfloat16`, `--quantize` 시 `nn.quantize(model.model, group_size=32, bits=8)`
- 이 저장소에 정밀도·양자화 측정 기록 없음

## 3. 방법 (실행 전 고정)

- 체크포인트: `t3_aria/ckpt/model-gen.safetensors`(#1807과 같음), MLX 0.25.2, Aria venv
- 팔 4개. 가중치와 KV 캐시 dtype 같이 변경, 양자화 범위는 데모와 같은 `model.model`(임베딩 포함, lm_head 제외)

| 팔 | 가중치 | KV 캐시 | 양자화 |
|---|---|---|---|
| fp32 | float32 | float32 | 없음(현행) |
| bf16 | bfloat16 | bfloat16 | 없음(데모 기본) |
| q8 | bfloat16 | bfloat16 | 8비트, 그룹 32(데모 `--quantize`) |
| q4 | bfloat16 | bfloat16 | 4비트, 그룹 32 |

- 입력: `mehldau_aria/data.json`의 test 녹음 첫 창 10개(1,017–1,024토큰, 실제 Mehldau 토큰)
- 시간 측정: producer와 같은 forward 호출(모델 호출, `mx.eval`, logits numpy 변환)을 `perf_counter_ns`로 측정. 샘플링·문법 마스크의 Python 비용은 제외
  - 문맥 L = 256, 512, 896. 첫 test 창 앞 L토큰을 미측정 프리필 후, 실제 다음 토큰 32개를 한 개씩 디코드(위치 L..L+31), 이어서 48토큰 suffix 프리필(#1807 블록 S 46 안팎) 1회
  - 팔마다 프리필 1회와 디코드 8스텝 예열. 반복 5회, 반복마다 팔 순서를 한 칸씩 회전, 네 팔을 같은 프로세스에서 교차 측정
  - 반복 시작과 끝 열 압력(`notifyutil`) 기록
- 분포 차이: test 창 전부(10개)를 팔마다 한 번에 forward. 위치마다 fp32 대비 KL(fp32‖팔), TV 거리, top-1 일치, 실제 다음 토큰 NLL
  - 실시간 경로는 온도 1 전체 분포 샘플링(`masked_pick`)이라 top-1보다 KL·TV를 주 지표로 사용

## 4. 판정 기준 (실행 전 고정)

- 무결성(미충족 시 측정 무효)
  - 모든 팔 logits 유한
  - fp32 같은 창 두 번 forward 최대 절대 차이 ≤ 1e-5
  - 열 압력 0이 아닌 반복은 표시하고 시간 판정에서 제외. 남은 반복이 3회 미만이면 시간 판정 보류
- 속도: 문맥 512 디코드 중앙값의 fp32 대비 비율. 0.75 이하면 속도 이득
- 분포 차이: 위치 평균 KL과 평균 TV
  - KL ≤ 0.02 nats, TV ≤ 0.05: 분포 차이 작음
  - KL ≤ 0.1: 청취 비교 필요
  - KL > 0.1: 실시간 후보 제외
  - 임계값은 보정 근거 없는 사전 선택. bf16(데모 기본) 값을 기준점으로 함께 보고
- 다음 단위 후보: 속도 이득이면서 분포 차이 작은 팔 중 가장 빠른 팔. 없으면 속도 이득이면서 청취 비교 필요인 팔 중 가장 빠른 팔을 청취 비교 단위로
- NLL 변화는 기록만, 판정 없음

## 7. 결과 (2026-10-18 17시대, 1회 실행)

무결성 전부 충족: 네 팔 logits 유한, fp32 반복 forward 최대 차이 0, 반복 5회 시작·끝 열 압력 모두 0. 반복 제외 없음.

| 팔 | 가중치(캐시 제외 환산) | 디코드 중앙값 L256 / 512 / 896 (ms) | 512 비율 | suffix 48 중앙값 L512 (ms) | KL 평균 | TV 평균 | top-1 일치 | NLL 평균 |
|---|---|---|---|---|---|---|---|---|
| fp32 | 2.63 GB | 11.13 / 11.32 / 11.83 | 1.000 | 35.8 | 기준 | 기준 | 기준 | 2.4982 |
| bf16 | 1.32 GB | 8.15 / 8.09 / 8.38 | 0.715 | 34.7 | 0.0006 | 0.0117 | 0.957 | 2.4983 |
| q8 | 약 0.77 GB | 5.90 / 6.07 / 6.25 | 0.536 | 35.3 | 0.0009 | 0.0139 | 0.954 | 2.4979 |
| q4 | 약 0.45 GB | 5.53 / 5.41 / 5.47 | 0.478 | 36.1 | 0.0444 | 0.0971 | 0.833 | 2.5371 |

- 디코드 표본: 팔·문맥마다 32스텝 × 5회 = 160. suffix 표본: 5. 분포 차이 위치: 10,203(test 창 10개)
- 보고서 `param_bytes`는 `model.parameters()` 전체 합이라 KV 캐시(4,160위치)와 causal mask 포함(fp32 3.47, bf16 1.74, q8 1.19, q4 0.88 GB). 표의 가중치는 캐시(fp32 0.82, bf16 0.41 GB)와 mask(0.02 GB)를 뺀 환산
- 위치별 KL 꼬리: p95 bf16 0.0015, q8 0.0022, q4 0.1311. 최대 bf16 0.038, q8 0.142, q4 2.557

판정(4절 기준 그대로)

- 속도 이득(512 비율 0.75 이하): bf16, q8, q4 모두 해당
- 분포 차이: bf16, q8 작음(KL 0.02·TV 0.05 이하). q4는 KL 0.0444로 청취 비교 필요 구간
- 다음 단위 후보: q8(속도 이득이면서 분포 차이 작은 팔 중 가장 빠름). q8의 KL·TV는 데모 기본값 bf16과 같은 크기
- NLL(기록만): bf16·q8 변화 0.0004 이하, q4 +0.039

관측

- 48토큰 suffix 프리필은 이 조건(표본 5회)에서 네 팔 중앙값 차이가 작음(34–37 ms). 디코드만 감소. 디코드는 가중치 읽기, 프리필은 연산 쪽 병목 후보(추가 검증 대상)
- bf16 L256 suffix 1회 342.6 ms 이상값(나머지 4회 34–36 ms). 제거하지 않고 평균·p95·최대에 포함. 원인 후보는 해당 형상 첫 호출의 커널 준비. 다른 팔에는 같은 이상값 없음, 추가 검증 대상. 중앙값은 이 꼬리를 지우지 않으므로 마감 보장 근거로 사용 불가
- 실시간 환산(추정, forward만, 샘플링·문법 마스크 Python 비용 제외): 마감 1박 469 ms에서 문맥·suffix 약 45 ms 제외 시 디코드 예산 약 424 ms. 문맥 512 중앙값 기준 fp32 약 37토큰, q8 약 70토큰
- #1807 블록 행에는 지평 도달까지의 샘플 수가 없어 실시간 토큰당 시간 산출 불가(`tokens`는 추측 생성분 포함). 실시간 경로의 토큰당 시간은 지평 도달 전 샘플 수를 따로 기록해 재측정 대상

- 분포 차이 범위: 문법 마스크 없는 teacher forcing, test 창 10개. 자유 생성, 음악성, 개인화 보존의 증명 아님
- 표의 가중치 크기는 환산값. 실제 peak memory나 가중치만의 실측 아님
