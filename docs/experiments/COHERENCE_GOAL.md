# 목표: 런타임 출력이 말처럼 이어지게 (사전 등록)

작성 2026-09-29. 이슈 #1572 연장. `style_verified: false` · `musical_quality_verified: false`

**이 절은 측정값을 보기 전에 작성했다.**

## 출발점 (사용자 청취)
사용자는 Tatum 런타임 출력을 두고 세 가지를 지적했다.
- "불협화음이 많고 막 누르는 것 같다"
- "기승전결이 없다"
- "말할 때 어순이 이어지지 않는 것 같다"

## 지표 (`scripts/coherence_metrics.py`)
- **윗선율:** 50 ms 안에 함께 친 음들 중 가장 높은 음을 잇는다. 다운비트의 왼손 저음은 선율 도약으로 세지 않는다
- **경계/내부 비율:** 윗선율이 생성 블록 경계(반 마디)를 넘을 때 도약 평균 ÷ 블록 안의 도약 평균
  - 실제 연주는 반 마디(128 BPM 기준 0.9375초) 창으로 잘라서 같은 값을 잰다
- **동기 재사용률:** 윗선율 음정 3-gram(4음) 중, 직전 8초 안에 겹치지 않는 위치에서 이미 나온 비율

## 목표 (모두 충족 + 청취 확인)
1. 선율 연속: 경계/내부 비율 ≤ 실제 연주 값 + 0.3(같은 연주자 기준)
2. 동기 재사용: 재사용률 ≥ 실제 연주 값 × 0.5
3. 화성 유지: 코드톤이 지금 런타임(A)보다 0.03 넘게 낮지 않다(모델·진행·seed로 짝지은 평균)
4. 실시간: 128 BPM 조건에서 fallback 0(미스는 보고만 한다)
5. 1–4를 통과한 후보만 사용자 청취로 최종 확인한다

## 1단계: 기준값 측정
- 실제 연주: Tatum 학습곡(`data/tatum_full/train`), 멜다우 16곡
- 런타임: A(지금 기본) 6회와 E(이력 → 코드) 6회. 모델별로 세 진행 × seed 2개(#1572 견고성 실행)다

## 1단계 결과 — 끊김보다 **동기 재사용 부족**이 결정적이다
원시값: `docs/experiments/coherence/baseline.json`.

| | 경계/내부 비율 | 동기 재사용률 |
|---|---|---|
| 실제 Tatum (110곡) | 1.277 | **0.073** |
| 실제 멜다우 (16곡) | 0.964 | **0.094** |
| A Tatum (6회) | 1.499 → 목표 ≤ 1.577 충족 | 0.001 |
| E Tatum (6회) | 1.183 | 0.009 |
| A 멜다우 (6회) | 1.213 → 목표 ≤ 1.264 충족 | 0.004 |
| E 멜다우 (6회) | 0.982 | 0.005 |
| B 연속 생성 Tatum, t 1.0 (1회, MIDI) | — | **0.000** |
| C 연속 생성 Tatum, t 0.8 (1회, MIDI) | — | **0.032** |

- 윗선율이 블록 경계에서 끊기는 정도는 A도 실제 연주 범위 안이다(목표 1은 이미 충족)
- 실제 연주자는 8초 안에 음정 패턴의 7–9%를 다시 쓴다. 모델 출력은 0.1–0.9%다. 기억을 넣은 E도 거의 늘지 않았다
- 끊지 않는 연속 생성(B)도 0이다. 반면 temperature를 0.8로 낮추면(C) 0.032가 된다. **샘플링 무작위성이 가장 큰 레버**로 보인다(각 1회, 인과 검증 전)

## 2단계 (사전 등록, 실행 전): temperature × 기억
- 런타임에 `--temperature`를 추가했다(기본 1.0, 기존 동작)
- 후보: A_t0.8, A_t0.7(기억 없음), E_t0.8, E_t0.7(기억 = `--context-carry-tokens 256 --context-history --context-carry-position before --max-sequence 512`)
- 조건: Tatum 완성·멜다우 #1497 × 세 진행 × seed 42, 반 마디 블록(24회). 목표를 충족한 후보는 seed 43으로 한 번 더 확인한다
- 판정: 위 목표 1–4. 여기에 **반복 상한 가드**를 더한다. 재사용률이 실제 연주 × 2를 넘으면 기계적 반복으로 보고 탈락시킨다
- 코드톤 비교 기준은 같은 seed의 A(t 1.0)다
