# 목표: 런타임 출력이 말처럼 이어지게 (사전 등록)

작성 2026-09-29. 이슈 #1572 연장. `style_verified: false` · `musical_quality_verified: false`

**이 절은 측정값을 보기 전에 작성했다.**

## 출발점 (사용자 청취)
사용자는 Tatum 런타임 출력을 두고 세 가지를 지적했다.
- "불협화음이 많고 막 누르는 것 같다"
- "기승전결이 없다"
- "말할 때 어순이 이어지지 않는 것 같다"

## 지표 (`scripts/coherence_metrics.py`)
- **윗선율:** 50 ms 안에 함께 친 음들 중 가장 높은 음을 잇는다. 다운비트의 왼손 저음은 선율 도약으로 세지 않는다
- **경계/내부 비율:** 윗선율이 생성 블록 경계(반 마디)를 넘을 때 도약 평균 ÷ 블록 안의 도약 평균
  - 실제 연주는 반 마디(128 BPM 기준 0.9375초) 창으로 잘라서 같은 값을 잰다
- **동기 재사용률:** 윗선율 음정 3-gram(4음) 중, 직전 8초 안에 겹치지 않는 위치에서 이미 나온 비율

## 목표 (모두 충족 + 청취 확인)
1. 선율 연속: 경계/내부 비율 ≤ 실제 연주 값 + 0.3(같은 연주자 기준)
2. 동기 재사용: 재사용률 ≥ 실제 연주 값 × 0.5
3. 화성 유지: 코드톤이 지금 런타임(A)보다 0.03 넘게 낮지 않다(모델·진행·seed로 짝지은 평균)
4. 실시간: 128 BPM 조건에서 fallback 0(미스는 보고만 한다)
5. 1–4를 통과한 후보만 사용자 청취로 최종 확인한다

- 런타임: A(지금 기본) 6회와 E(이력 → 코드) 6회. 모델별로 세 진행 × seed 2개(#1572 견고성 실행)다

## 정정 (Astra 재리뷰 @0696d103)

### 표기
- 이 문서의 지표(윗선율 onset, 고정 시간 음정 3-gram)는 **제한적인 대리 지표**다. 음악적 일관성의 근거가 아니다(실제 곡은 박자에 정렬돼 있지 않고, 음 밀도에 따라 가중된다)
- 목표식(실제 + 0.3, 실제 × 0.5, 상한 × 2)은 **탐색용 공학 기준**이다
- 1–3단계는 모두 같은 seed 42 결과를 보고 설정을 바꾼 **탐색**이다. 독립 확증이나 품질 성공으로 쓸 수 없다

### M1 — 지표 계측 결함과 재계산
- **결함:** 여러 파일을 묶을 때 마지막 파일의 블록 길이를 모든 파일에 썼다. 블루스(120 BPM) 실행이 128 BPM 경계로 잘렸다
- **수정:** 파일마다 자기 생성 블록 길이(`block_beats`, 없으면 마디 ÷ `chord_blocks_per_bar`)로 자른다. 회귀 테스트는 Astra의 재현(120 BPM 경계 [1] / 내부 [12])이다
- **재계산**(`docs/experiments/coherence/baseline_v2.json`, `step2_judge_s42_v2.json`, `step3_judge_s42_v2.json`)

  | | 경계/내부 (전 → 후) | 목표 |
  |---|---|---|
  | A Tatum | 1.499 → **1.743** | ≤ 1.577 ✗ |
  | E Tatum | 1.183 → 1.191 | ✓ |
  | A 멜다우 | 1.213 → **1.352** | ≤ 1.264 ✗ |
  | E 멜다우 | 0.982 → 0.997 | ✓ |

- **1단계 결론 정정:** "경계 끊김은 A도 실제 범위 안(목표 1 충족)"은 **틀렸다.** 지금 런타임은 블록 경계에서 실제 연주보다 크게 끊기고, 기억(E)은 이를 실제 수준으로 줄인다. 동기 재사용 결론은 위치와 무관한 지표라 바뀌지 않는다
- 2·3단계 표의 경계/내부 열도 바뀌었다(위 v2 파일). 전 조건을 충족한 후보가 없다는 결론은 같다

### E 계열 실행에 대한 단서
2·3단계와 견고성 확인의 E 실행은 **고치기 전 이력 구현**으로 생성했다(`CONTEXT_HISTORY.md`의 M3 정정 참조). 생성 직후 토큰을 쌓았고, 블록마다 약 7.5 ms 시간 오차가 누적됐다. fallback이 난 실행에서는 늦게 버려진 블록도 이력에 들어갔을 수 있다.
