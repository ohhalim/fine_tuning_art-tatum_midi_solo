**A. 성공 기준**

1. 💭 우선순위는 이렇게 봅니다.
   1. 코드에 심하게 어긋나지 않음
   2. 실제 비밥 피아니스트처럼 들리는 솔로 (릭이 들어간 선율)
   3. 내가 친 코드에 1블록(반마디) 안에 반응
   4. Mac 단독 실시간
   5. 다양성
   6. Tatum/Mehldau 개성
   7. 구현 단순성

   지금까지 피드백은 대부분 "불협", "컴핑이 이상함", "릭이 없음"이었습니다. 프로젝트 목표는 내가 실제 연주에 쓰는 것, 3분 데모, 교체 가능한 어댑터와 지표가 찍히는 구조입니다.
2. ✅ 솔로 + 별도 컴핑. 지금 구성은 오른손 단선율 솔로에 규칙 기반 컴핑을 얹은 것입니다.
3. 💭 결과만 좋으면 구조는 상관없음 (검색 + 생성 혼합 포함). 다만 규칙으로 음을 다시 고르는 방식(L1–L3)은 귀로 기각했습니다.
4. 💭 허용. 웨이트나 코드를 공개할 경우 전사된 릭을 쓰는 데 따른 권리 문제는 따로 확인해야 합니다.

**B. 현재 시스템**

5. ✅ 라이브 프리셋 `bebop`:
   - 체크포인트: `outputs/bebop_rh/export/checkpoint_update516.pt`
   - base: Music Transformer(relative attention) 13.4M, 재즈 2,777조각으로 사전학습
   - LoRA r16 (QKV + out_proj)
   - LoRA 학습 데이터: 비밥 피아니스트 13명, 235곡의 오른손 선율 (train 189곡)
   - 그 밖의 프리셋: Tatum, Mehldau 어댑터
   - 귀로 통과한 체크포인트는 아직 없습니다.
6. ✅ 파이프라인 순서:
   1. FL Studio 타이핑 키보드 → FL MIDI Out → IAC "AI In"
   2. 눌린 음으로 코드 판별
   3. 반마디 블록마다 프롬프트 구성 (저음역 코드 가이드 voicing + 직전 솔로 토큰 carry)
   4. Music Transformer + LoRA 생성
   5. 단선율 필터 (50 ms 묶음마다 최고음, 음역 하한)
   6. (옵션) 화성 bias, 후보 N개 중 선택, 프레이즈 쉼
   7. 규칙 컴핑 합성 (근음 + 3·7음 등)
   8. 스케줄러 → IAC bus 2 → Serum
7. ✅ 블록당 96~128 토큰. 블록은 반마디로, 128 BPM에서 0.94초입니다. 토큰은 10 ms 격자 이벤트입니다.
8. ✅ 측정값:
   - 기기: Apple M1 Max, RAM 32 GB
   - 블록 생성 시간 (후보 1개): p50/p95/p99 = 97/176/219 ms
   - 후보 2개: 166/275/355 ms
   - 실제 블록 예산: 약 419 ms
   - 키 입력부터 소리까지 왕복 지연은 아직 측정하지 않았습니다.
   - 시스템 정지로 1,184 ms 늦어진 사례가 한 번 있었습니다.
9. ✅ 블록 안 생성에는 KV 캐시를 씁니다. 블록 사이에는 상태를 유지하지 않고, 매 블록 가이드 + carry 프롬프트를 다시 계산합니다 (최대 512 토큰).
10. ✅ 생성 방식:
    - temperature 0.6, top-k 32, top-p 0.95
    - grammar mask (문법에 어긋나는 토큰 차단)
    - beam 없음
    - 옵션: 후보 N개를 만들어 코드톤·반복 점수로 선택, 회피음 logit 감점, 반복 penalty
    - 기본값은 후보 1개 (예산 때문)

**C. 성공과 실패**

11. ✅ 귀로 가장 나았던 것은 R2입니다. 실제 비밥 피아니스트 프레이즈의 리듬과 윤곽을 유지하고 음높이만 코드에 맞춰 다시 고른 방식입니다. 평은 "제일 안정적이지만 릭 같은 솔로가 거의 없다"였습니다. BebopNet 샘플(N1/N2)은 아직 판정 전입니다.
12. ✅ 버린 방식:
    - 모델 출력에 후처리 규칙을 계속 쌓는 것 (회피음 bias, 화성 마스크, 반복 penalty, 후보 ranking). 지표는 좋아졌지만 귀로는 여전히 불협이었습니다.
    - 코드 가이드를 붙여 LoRA를 다시 학습한 것. 형식에만 적응하고 코드를 반영하지 않았습니다.
    - 릭 뱅크 L1–L3 (음 재선택 + 스윙 후처리). 평가는 "뚱땅거리고 불협"이었습니다.
    - 이전 통제 실험에서 기각한 것: 오디오 모델로 전환, 모델 키우기, 12키 전조 증강, full fine-tune.
