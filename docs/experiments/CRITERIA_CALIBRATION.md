# 사전 거름 지표 보정: 좋다고 고른 연주 대 거절한 출력 (사전 등록)

작성 2026-10-18 09:5x KST. 이슈 #1762의 남은 할 일 "판정 기준 다시 정하기"의 첫 단계입니다. 새 생성·학습·청취 없음. `quality_claimed: false`.

## 1. 왜

- `REALTIME_PARTNER_RESEARCH.md` 2절의 C1–C9는 기준 클립을 고르기 전에 만든 임시안입니다
- 03-VALIDATION-ROADMAP에 따라 **G1(쓸 수 있는 솔로)의 판정은 사용자 청취**입니다. 자동 지표는 "사용자에게 보내기 전에 뻔한 실패를 거르는" 용도로만 씁니다(메모리: 뻔한 실패는 사용자 전에 거르기)
- 그동안 사용자가 반복해서 지적한 실패가 있습니다: "두 배 빠른 재즈"(빽빽함), "컴핑과 솔로가 섞임", "릭 같은 게 없다 / 진짜 멜로디"(릭 없음), ReaLchords의 8분만 이어지는 선율(사용자 "별로"), "다 별로"(Aria·JPS 16칸)
- 거름 지표의 임계값은 숫자를 먼저 정하지 않고, **실제 연주와 거절된 출력으로 보정한 뒤** 정합니다(메모리: 게이트 임계값 보정)

## 2. 질문 (하나)

아래 자동 지표 중, 사용자가 좋다고 고른 연주(L)와 사용자가 거절한 출력·클립(N, R)을 실제로 가르는 것은 무엇인가?

- 판정 기준을 이 결과만으로 확정하지 않습니다. 결과는 아스트라와 합의할 기준 초안의 근거입니다

## 5. 읽는 법

- 묶음별 중앙값과 범위를 냅니다. 통계 검정은 하지 않습니다(표본 작음, R1 비독립)
- "가른다"의 기준(서술용): L 8개의 [최솟값, 최댓값] 범위 밖에 R1의 과반과 R2의 과반이 있으면 "거절 출력과 갈림", N의 과반이 있으면 "비선호 클립과 갈림"으로 적습니다. 이 기준도 결과 전에 고정합니다
- 갈리는 지표만 거름 후보로 올리고, 임계값은 L 범위에서 여유를 둔 값으로 아스트라와 정합니다. 갈리지 않는 지표는 거름에 쓰지 않는다고 적습니다
- 스윙(C5)은 박 정보가 없는 PiJAMA 클립에서 잴 수 없어 이번에 빠집니다
