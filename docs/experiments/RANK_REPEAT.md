# avoid 벌점 + ranker 반복 항 (사전 등록)

작성 2026-10-03. 이슈 #1660. Claude 혼자 진행한다. 판정 규칙은 실행 전에 고정했다. `musical_quality_verified: false`.

## 근거
- #1656: avoid 벌점 2.0은 불협을 줄였지만 같은 음 반복을 늘렸다(.175)
- #1658: 생성 단계 반복 벌점 1.5는 반복을 .042까지 줄였지만 두 가지 문제가 생겼다
  - p99 432 ms로 예산을 넘었다
  - 블록 안 음정 p90이 10 → 17로 커졌다(실제 9)
- 이번에는 반복을 생성 단계가 아니라 **후보 2개 중 고르는 기준**에 넣는다. 추가 생성 연산이 없고, 두 후보 모두 모델이 낸 선율이라 도약을 강요하지 않는다

## 변경
- `--rank-repeat-weight W`: ranker 점수 = fit − clash − W × (같은 음 연속 비율). W = 0이면 기존 ranker와 같다(동등성 테스트 유지)
- **W = 0.5로 고정한다**(fit − clash 범위가 −1..1이라 반복 비율 0.2 차이가 점수 0.1에 해당한다). 다시 고르지 않는다
- 스모크(8마디, 측정 아님): 오류 0, 대체 0

## 실행
- 새 팔 `bias2rank0.5`: 청취 설정 전체 + `--harmony-bias 2 --rank-repeat-weight 0.5`(생성 반복 벌점 없음). holdout 진행 3개 × seed 42·43
- 기준선: #1656의 bias0 6회
- `dissonance_check.py --label bias2rank0.5 --bias 2 --rank-weight 0.5`

## 판정 (실행 전 고정)
1. avoid 음 시간 ≤ bias0의 0.5배
2. 컴핑과 동시 충돌 시간 ≤ bias0의 0.7배
3. 박 위 clash ≤ bias0 + 0.01
4. 경계 ≥ 9 비율 ≤ 0.22, 경계 p50 ≤ 4
5. 같은 음 반복 ≤ bias0(.109), 시작 음정 고유 비율 ≥ bias0의 0.9배, 복사 블록 ≤ 0.05
6. **블록 안 음정 p90 ≤ bias0 + 2(12)**: #1658에서 놓친 도약 위험
7. 초당 음 수와 쉼이 데이터 범위 안
8. 대체 0, miss ≤ 2, invalid 0, p99 ≤ 419 ms
