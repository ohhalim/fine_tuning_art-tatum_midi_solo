## 근거
- 각 수단이 늘린 IR(Tatum, fresh12, 기준 0.007)

  - 패턴 캐시 ln 3: +0.006(#1604)

## 질문 (하나)
T 0.6에서 패턴 캐시를 켜면 IR이 실제의 절반 이상이 되는가. 같은 T에서 끈 것보다 확실히 높아야 하고, 기계적 반복이나 복사가 없어야 한다.

## 설계·판정
- #1604와 같다(`scripts/pattern_cache_diag.py --temperature 0.6`). 위치·자연 문맥·seed·모델·데이터도 같다
- 두 갈래(끔/켬) 모두 T 0.6을 쓴다
- **통과:** 모두 충족
  1. IR(켬) ≥ 0.5 × 실제 IR
  2. IR(켬) − IR(끔) 곡 CI 하한 > 0
  3. 보호 조건
     - 반복률 ≤ 실제 + 0.15
     - 복사 비율 ≤ max(0.25, 실제 × 2)
     - 유효율 ≥ 0.9
- 통과하면 런타임 opt-in과 청취 확인을 별도 이슈로 만든다. 기본값은 바꾸지 않는다
