## 4. 표본 크기 근거 (실행 전 계산)

- Wilcoxon signed-rank의 matched-pairs rank-biserial r과 검정 통계량의 관계(정규 근사): z ≈ r · √(3n) / 2 ≈ 0.866 r √n
- |r| = 0.15, 양측 α 0.01, 검정력 0.8: 필요한 z = 2.576 + 0.842 = 3.418 → n ≈ (3.418 / (0.866 × 0.15))² ≈ 692
- n = 768에서 |r| = 0.15의 기대 z ≈ 3.60, 검정력 약 0.85. #1830 관측 크기(|r| 0.27)는 거의 확실히 검출되는 크기

## 5. 판정 기준 (실행 전 고정)

- 주 통계 하나: 초당 음 수(`notes_per_s`, 30초 구간 음 수 ÷ 30). 다중 비교 회피
- 짝 차이 d = q8 − fp32. Hodges–Lehmann 추정(Walsh 평균의 중앙값)과 signed-rank 역산 99% 구간(정규 근사, 0 차이 포함). Wilcoxon signed-rank 양측 p(0 차이 제외, #1830과 같은 구현)와 r 기록
- 판정은 99% 구간으로만:
  - 구간 상한 < 0: q8 성김 검출. 구간이 [−0.3, +0.3] 안이면 "실용 차이 범위 안", 아니면 "실용 차이 범위 밖 가능"
  - 구간 하한 > 0: q8 조밀함 검출(같은 구분)
  - 0을 포함하고 [−0.3, +0.3] 안: 실용 차이 없음
  - 그 외: 미결
- 실용 차이 범위 ±0.3음/초의 근거: #1830 fp32 중앙값 6.45의 약 5%. 128 BPM 2박 창(0.9375초)으로 0.28음, 지평 전 샘플 약 0.85개(음당 토큰 3개, #1819), q8 샘플당 약 6.4 ms 기준 블록당 약 5 ms. 이보다 작은 차이는 마감 비교와 밀도 판단에서 무시 가능하다고 사전 판단. 음악적으로 들리는 차이인지는 별도(청취)
- #1830 방향 재현: 주 통계 HL 추정이 0보다 작으면 "방향 재현"
- 보조(판정에 안 씀): `win_max`, `win_median`(2박 창 32개의 음 수 최대·중앙값)의 HL 추정·99% 구간·p, 프롬프트별 HL
- 유효성: 모든 실행 형식 유효·30초 도달 여부, 누락 짝 기록. 누락이나 무효가 있으면 판정에 함께 표시
- 샘플당 시간은 이 단위에서 재지 않음(실행 시간 `seconds`는 기록만, 열·잠금 대기 섞임)
- 결과를 본 뒤 기준·통계·n 변경 없음
