# T3c: Aria가 티그랑 하마시안 연주를 이어 치기 (사전 등록)

작성 2026-10-04. 선행: `T3_ARIA.md`. 아스트라 #192 합의. `musical_quality_verified: false`.

## 계기 (사용자 원문)
T3 청취 직후 사용자가 연속으로 보낸 메시지:
- "나는 Tigran Hamasyan(티그랑 하마시안, piano 같은 느낌의 솔로잉을 원하거든?"
- "스윙재즈느낌 난 별로 안좋아해"
- "비밥이나 티그랑 같은 스타일 좋아햐"

**해석의 한계**
- 이 선호가 코드 제어 요구를 철회한다는 뜻은 아니다
- 앨범 하나("A Fable")가 연주자 전체 스타일을 대표한다는 보장은 없다
- 홀수 박자나 모달 같은 성격은 MIDI만 보고 확정하지 않는다. 검증할 수 없으면 태그를 붙이지 않는다

**스윙에 대한 기록**
- 사용자는 스윙 재즈를 선호하지 않는다고 명시했다
- 과거 일부 클립(T1 CMT, C1 반주, 릭 묶음)에는 2:1 스윙을 렌더 처리로 넣었다. BebopNet은 자체 스윙 출력이다. T3 Aria에는 스윙을 넣지 않았다
- 과거 비선호 판정에 스윙이 기여했는지는 분리 실험을 하지 않았다. 과거 판정과 결함 기록은 그대로 둔다
- 앞으로는 **인위적 스윙을 추가하지 않고, 원본과 모델의 미세 타이밍을 보존한다.** 스트레이트로 양자화하는 것이 아니고, 원데이터에 내재된 스윙을 되돌리지도 않는다

## 질문 (하나)
Aria가 티그랑 "A Fable"의 실제 연주 8초를 이어 친 생성 부분이, 사용자가 원하는 느낌에 더 가까운가. 좋아진 부분과 남은 문제는 무엇인가.

- 작은 스타일 탐색이다. 새 학습이나 개인화 성공 실험이 아니다
- 결과가 좋아도 결론은 "티그랑 프라이머로 이어 친 결과를 사용자가 선호했다"까지다. 어댑터 개인화나 임의 곡 협연을 검증한 것이 아니다

## 계약 (T3와 같음)
- 공식 CLI `aria generate --backend mlx`, `model-gen.safetensors`, T3의 `max_kv_pos` 로컬 패치(logits 동일 확인)
- `--temp 0.98 --min_p 0.035 --length 1024 --prompt_duration 8 --variations 2`
- 반복 패널티, 음역 마스크, velocity 평탄화, 스윙은 추가하지 않는다. 양손 원본을 그대로 쓴다
- 4개(프라이머 2 × 변형 2)를 전부 보고한다

## 프라이머 (생성 전에 입력 통계로 고정)
- 데이터: PiJAMA 전사 Tigran Hamasyan "A Fable"(2011 솔로 피아노), 13곡 53.2분, `midi_dataset/midi/studio/Tigran Hamasyan`
- 후보: 20초부터 10초 간격의 8초 창 277개. 아스트라 권고대로 한 가지 성격(밀도)만 최대화하지 않고, 성격이 다른 구간 두 개를 쓴다
  - **TA(활발한 라인):** 오른손 밀도가 가장 높은 창. "What The Waves Brought" 110–118초. 양손 16.5음/초, 오른손 10.1음/초, 빈 0.25초 칸 0%, 음역 34–92
  - **TB(선율과 쉼):** 양손 밀도가 전체 중앙값(9.5음/초)에 가깝고 빈 칸이 25% 이상인 창 중, TA와 다른 곡의 첫 번째. "The Legend Of The Moon" 180–188초. 양손 9.4음/초, 오른손 2.1음/초, 빈 칸 31%, 음역 31–86
- 원 MIDI 양손 그대로 잘라 0초로 옮긴다. 페달 CC는 원데이터에 없다

## 보고
- 생성 부분만 평가한다. 프라이머와의 경계는 T3처럼 프라이머 토큰 출처로 확인한다
- 덤프: 밀도, 음역, 반복·맴돌기(시간과 연속 구간으로), 프레이즈
- **원곡 바로 다음 구간(118–126초, 188–196초)과의 유사도**를 보고한다. 생성 앞 8초의 윗성부 음정열과 원곡의 같은 구간을 4음정 n-gram 일치로 비교한다
  - 비슷하다고 무조건 암기로 보지 않고, 다르다고 복사가 없었다고 보지도 않는다. Aria 사전학습에 이 녹음이 들어갔는지는 미확인이다
- 청취 파일은 중립적인 이름으로 올린다. "티그랑 같은가"처럼 이름으로 유도하는 질문 대신 "원하는 느낌에 더 가까운가, 좋아진 부분과 남은 문제"를 묻는다. 실제 연주와 생성의 경계는 분명히 표시한다

## 결과

### 경계
- 프라이머 토큰(TA 399, TB 228)을 MIDI로 되돌려 4개 출력과 대조했다. 프라이머 음 전부(TA 132, TB 75)가 그대로 들어 있었다
- 생성 부분은 출력 음 중에서 프라이머 음을 (pitch, onset 10 ms 반올림) 다중집합으로 하나씩 지운 나머지다. 같은 음을 다시 친 경우도 개수대로만 지운다. end와 velocity는 대조하지 않았다. 아스트라는 문서만 봤고 코드를 다시 검증하지는 않았다

### 출력 (4개 전부)
| 클립 | 생성 음 / 초 | 초당 음(양손) | C4 이상 비율 | 음역 | 반복(2초 창, 윗성부 ≥ 8음인데 음 종류 ≤ 3) | 저음만(2초 창) |
|---|---|---|---|---|---|---|
| A-1 (TA) | 339 / 17.2 | 19.7 | .67 | 39–84 | 없음 | 없음 |
| A-2 (TA) | 340 / 22.1 | 15.4 | .69 | 34–87 | 4초부터 끝까지(C#5 반복 타격) | 없음 |
| B-1 (TB) | 339 / 30.2 | 11.2 | .42 | 26–86 | 22–28초 | 22–28초 |
| B-2 (TB) | 339 / 26.2 | 12.9 | .58 | 26–87 | 22초 | 없음 |

- **반복 결함이 다시 나왔다.** 두 수를 구분한다
  - 감지기(2초 창, 윗성부 ≥ 8음인데 음 종류 ≤ 3)에 걸린 클립: 3/4(A-2, B-1, B-2)
  - 길게 이어진 루프: 2/4. A-2는 이어 친 지 4초쯤부터 끝까지 C#5 반복이다. B-1은 마지막 6초가 저음 반복이다. B-2는 2초 창 하나만 걸렸다
  - 의도된 오스티나토인지 원치 않는 루프인지는 길이만으로 정할 수 없다. 프라이머 자체의 반복과 비교하고 사용자 판정과 함께 해석한다
- "C4 이상 비율"과 "윗성부"는 실제 오른손 라벨이 아니다. B-1의 22–28초는 "저음만" 조건(2초 창의 6음 이상이 모두 C4 아래)과 윗성부 반복 조건에 함께 걸렸다
- 샘플마다 생성 길이(17–30초)가 달라서, 1024토큰 고정 생성의 루프 발생을 같은 시간 노출 기준의 실패율로 일반화하지 않는다

### 원곡 다음 구간과의 유사도
- 4음정 n-gram 일치(생성 앞 8초 대 원곡 다음 8초, 분모는 생성 쪽 n-gram 수): A-1 0.0, A-2 0.158, B-1 0.167, B-2 0.071
- 대조: 원곡 다음 구간과 같은 곡의 다른 구간(TA는 150–158초, TB는 220–228초)은 공유 n-gram 0이었다. n-gram 수는 TA 78 대 47, TB 10 대 9다. TB는 n-gram 수 자체가 적다
  - 0은 복사가 없다는 뜻이 아니다. 높은 값도 짧은 반복 패턴 때문일 수 있다. 대조 하나로 암기를 판정하지 않는다
- 윗성부를 직접 비교하면 더 분명하다
  - **A-2의 생성 첫 약 1.5초는 원곡의 바로 다음 구간과 거의 같다.** C#6–G#5–F5–C#5–G#4–F4–C#4–C#5…이고 시각도 거의 같다. 프라이머에서 반복되던 아르페지오 패턴을 이은 것인지, 원곡을 외운 것인지는 구분할 수 없다
  - B-1·B-2는 원곡처럼 왼손 D4–G3 동기를 잇고, 그 위에 G–A–Bb 선율을 둔다. 원곡의 다음 부분(A5–G5–G5–A5–A#5)과 비슷한 재료다
- Aria 학습 데이터에 이 앨범이 들어갔는지는 확인하지 않았다. 따라서 "원하는 스타일처럼 들린다"가 일부는 원곡 복사에서 왔을 수 있다

### 청취
- 페이지에 A-1, A-2, B-1, B-2를 중립적인 이름으로 올렸다. 앞 약 8초가 실제 연주임을 표시했고, 반복 구간과 A-2의 원곡 유사를 미리 적었다
- 결함을 미리 알린 안내 청취(annotated exploratory listening)이므로 블라인드 청취가 아니다. 중립 이름만으로 편향이 없어지지는 않는다
- sha1 앞 12자리: A-1 e6de26de7af9, A-2 9a53290c5bc1, B-1 cfcb59ed7d90, B-2 53b459ad3f66
- **사용자 판정: 대기 중.** 판정이 오기 전에는 이 결과를 성공으로 쓰지 않는다

### 허용되는 결론 범위 (아스트라 종합 리뷰 10/6)
- T3까지 말할 수 있는 것은 "사용자가 이번 Aria 양손 이어 치기 샘플을 이전에 제공한 샘플보다 음악처럼 들린다고 평가했다"까지다
- 모델 자체의 우열, "커서 좋아졌다", 티그랑 개인화, 코드 제어, 실시간 성공은 검증하지 않았다. 양손 대 단선율+반주, 프라이머, 인위적 스윙, 표현력 조건이 서로 다르다
- T3c는 실제 연주 8초를 이어 친 것이지 학습된 개인화가 아니다
- 작은 모델 LoRA의 likelihood 특화 결과와 Aria 청취 결과는 별개의 증거다
