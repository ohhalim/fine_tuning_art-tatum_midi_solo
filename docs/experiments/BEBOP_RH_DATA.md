# 비밥 피아니스트 오른손 선율 데이터 (#1616)

작성 2026-10-02. 로컬 데이터만 쓴다(외부 다운로드 없음). `musical_quality_verified: false`.

## 왜
- 사용자 청취: 모델 출력은 재즈 느낌은 있다. 그런데 너무 빠르고("두 배 빠른 재즈"), 컴핑과 솔로가 섞이며, 릭 같은 솔로잉으로 들리지 않는다
- 음 분포로 보면 이렇다
  - 모델은 초당 14–17음이다. 실제 Tatum 녹음 9.8음, 멜다우 5.1음보다 빽빽하다
  - 실제 Tatum과 멜다우 녹음도 윗선율에 쉼이 거의 없다(쉼이 차지하는 시간 3%, 1%). 양손 솔로 피아노이기 때문이다
  - 그래서 모델은 쉬지 않는 솔로 피아노를 배웠다. 숨 쉬는 릭 솔로는 배우지 않았다. 학습 재료와 목표 소리가 다른 장르다
- 그동안의 지표(동기 재사용, 코드톤)는 이 문제를 잡지 못했다. 분포를 먼저 봤어야 했다

## 만드는 법 (`scripts/build_rh_dataset.py`)
- 피아니스트 13명(로컬 `midi_dataset/midi/{live,studio}`)
  - Barry Harris, Cedar Walton, Hank Jones, Duke Jordan, Kenny Barron, Tommy Flanagan, Junior Mance
  - Harold Mabern, Mulgrew Miller, Red Garland, Benny Green, Kenny Drew, Bill Charlap
  - Oscar Peterson, Dave McKenna, Monty Alexander는 런이 빽빽하거나 스트라이드 성향이라 뺐다
- 오른손 추출 방법
  - 50 ms 동시 타건 묶음마다 최고음 하나를 남긴다. G3(55)보다 낮으면 왼손 컴핑으로 보고 버린다(그 자리는 쉼이 된다)
  - 남긴 음은 다음 음 시작에서 끝낸다(단선율)
  - 기존 데이터와 같은 인코더(`encode_notes_simple`)를 쓴다
- 분할: 곡(파일 sha1) 단위로 결정적으로 나눈다(test 10%, val 10%, train 80%). 같은 파일은 한 번만 쓴다
- 출력 `data/bebop_rh/{train,val,test}`, `manifest.json`(출처·분할·통계). git에는 올리지 않는다
- 주의: 공통 base는 이 피아니스트들의 **양손** 녹음으로 사전학습했다. 오른손만 뽑은 형태는 처음 보지만, 같은 곡의 정보를 이미 본 셈이다. 그래서 가능도로 "처음 보는 곡"이라고 주장하지 않는다
