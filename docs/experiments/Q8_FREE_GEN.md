## 4. 실행 단위 통계 (실행 전 고정)

t0 ≤ onset < t0 + 30 s 음 기준.

| 통계 | 정의 |
|---|---|
| notes_per_s | 음 수 ÷ 30 |
| pitch_median, pitch_range | 음높이 중앙값, 최고 − 최저 |
| chord_share | onset 30 ms 묶음 중 2음 이상 묶음에 속한 음 비율 |
| ioi_median_s | 묶음 시작 간격 중앙값 |
| dur_median_s | 음 길이 중앙값 |
| vel_median | 세기 중앙값 |
| rest_share | 30초 중 울리는 음이 없는 시간 비율 |
| win_max, win_median | 2박 창(937.5 ms, 128 BPM) 32개의 음 수 최대·중앙값 |

- 형식 유효성: `aria_token_validity.check`(무효 또는 끝이 음 중간이면 무효). 종료 사유(30초 도달, 토큰 상한, 허용 질량 0) 기록
- 짝별 첫 분기 토큰 위치 기록

## 5. 판정 기준 (실행 전 고정)

- 주 검정: 통계마다 짝(프롬프트, seed) 차이 q8 − fp32에 Wilcoxon signed-rank(0 차이 제외, 정규 근사, 동순위 보정, 연속성 보정 없음). 효과 크기는 matched-pairs rank-biserial r
- 차이 검출: p < 0.005(10개 통계 Bonferroni, 가족 0.05)이고 |r| ≥ 0.3
- 판정: 검출 통계 0개이고 두 팔 모든 실행 형식 유효면 "이 n에서 검출된 차이 없음". 하나라도 검출이면 "차이 검출"과 해당 통계. 형식 무효 실행이 있으면 함께 표시
- 유의성 문턱(사전 계산): 짝 128에서 p < 0.005가 되는 |r|은 약 0.29(정규 근사). 검출력 보장 값은 아님(10절 정정). "검출 안 됨"은 "같음"이 아님
- 보조(판정에 안 씀): 짝 차이 중앙값과 부트스트랩 95% 구간(2,000회, seed 0), 합쳐서 본 Cliff's delta, 프롬프트별 중앙값
- 결과를 본 뒤 기준·통계 목록·n 변경 없음

## 10. 리뷰 반영 (아스트라 M2·M3, 결과 뒤 추가, 판정 불변)

- 입력 조건(M2): 판정 전 기대 (프롬프트, seed) 128개가 정밀도마다 정확히 한 번, 형식 유효, 30초 도달(`stop` = duration)인지 검사. 하나라도 어긋나면 "판단 불가"와 종료 코드 2. 빈 파일·누락·중복·max_tokens 회귀 시험 추가. 저장 자료 재판정: 조건 충족, 통계 값 기존 보고와 동일
- seed 공유 잡음(M3): 프롬프트 4개가 같은 seed 1~32를 쓰므로 같은 seed의 4짝은 샘플링 잡음을 공유. 128짝 독립 가정의 Wilcoxon은 근거가 약함. 등록 판정(검출 차이 없음)은 유지하고 한계로 기록
- 사후 민감도(새 확증 아님, 추정 대상이 다름): seed별로 4프롬프트 차이 평균 → 32개 signed-rank. 초당 음 수 중앙 −0.56, p 0.0071, r −0.55. 2박 창 최대 −1.38, p 0.0016, r −0.66. 2박 창 중앙 −0.5, p 0.037. 나머지 p ≥ 0.056
- 해석: 128짝 등록 분석의 "검출 없음"과 seed 묶음 분석의 "q8 성김 방향"이 갈림. 새 seed 768짝 후속(#1832)은 등록 분석에서 실용 차이 없음(HL −0.05, 99% [−0.22, +0.13])이었고, 같은 seed 공유 구조라 같은 민감도를 #1832에도 추가해 판단
- |r| 0.29는 유의성 근사 문턱이지 검출력 보장 아님(5절·9절 문구 정정)
