작성 2026-10-03. 이슈 #1665. 사용자 요청으로 방식을 바꿨다. 아스트라와 토의해서 결정했다. `musical_quality_verified: false`.

  - H1/H2(avoid 벌점 등): "아직도 불협이 많아, 컴핑도 그지같고"
  - "MIDI 파일 보면 바로 알 수 있는데"
  - "이전에 했던 방법대로는 결과가 안 바뀔 것 같아, 논문을 찾든 아스트라와 이야기하든 해결책을 가져와"
- 지금까지 한 일(#1656–#1662)은 모델이 뽑는 음의 확률을 밖에서 조정하는 패치였다. 합산 지표는 좋아졌지만 들리는 불협이 남았다
- 확률을 더 세게 막는 clean mode(엄격한 스케일 마스크 + 해결 강제)는 MIDI 결함을 0으로 만들었다. 대신 반복이 20%로 무너졌다(실제 5.5%)

## MIDI 직접 진단 (listen_v4 iiVI, 마디별 덤프)
1. 모델이 낮은 음만 칠 때 그 음이 솔로 맨 위 선율로 들어간다. G5 → G3 → B3 → G5처럼 2옥타브씩 급강하한다. 렌더에 솔로 음역 하한이 없었다
2. varied 컴핑은 9음을 포함한 rootless 보이싱이고 E3–E4에 있다. 그래서 솔로 하단과 겹친다(Dm7: 컴핑 F3-C4-E4 vs 솔로 F4 → E와 F가 반음). 컴핑 최고음이 솔로보다 위인 경우도 있다
3. 소프트 벌점이라 avoid 음 일부가 그대로 나온다(Dm7 위 Gb5)
- 6회 계수(`scripts/midi_defects.py`, 현재 정의의 proxy. unknown 분리와 코드 경계 판정은 미보완): harsh(동시 단2/장7/단9) 4.7%, 컴핑 ≥ 솔로 1.6%, 솔로 C4 미만 3.8%, 해결 안 된 스케일 밖 음 8.7%, 반복 10%, 옥타브 넘는 도약 9.2%

## 문헌 (직접 확인)
- **BebopNet**(Haviv Hakimi et al., ISMIR 2020 Best Research Award)
  - 음마다 입력에 현재 코드 4음이 들어간다. 비밥 솔로(MusicXML + 코드)로 학습했다
  - 코드와 사전학습 체크포인트를 MIT로 공개했다
  - https://github.com/shunithaviv/bebopnet-code
- **Frieler & Zaddach**(TISMIR): mid-level unit(line/lick)과 Weimar Bebop Alphabet, 코드-스케일 이론으로 음을 고른다
  - 튜링 테스트 전문가 정답률 64%
  - 표현(마이크로타이밍·아티큘레이션)이 음 내용만큼 중요하다고 결론냈다
  - https://transactions.ismir.net/articles/10.5334/tismir.87
- **Impro-Visor**(Keller; Gillick/Tang/Keller CMJ 2010): 추상 멜로디(리듬·윤곽·음 범주)를 만들고 코드에 맞게 실현한다
  - http://ai.stanford.edu/~kdtang/papers/cmj10-jazzgrammar.pdf
- **Chord-conditioned melody and bass**(arXiv 2511.08755): 명시적인 코드 조건이 코드톤 사용 재현을 개선한다
- 공통점: 코드를 음 선택에 직접 넣는다(학습할 때든 구성할 때든). 우리 모델은 코드를 배운 적이 없다

## 결정 (아스트라와 합의)
- **A:** 프레이즈 계획 + 화성 실현을 오프라인 진단 1단위로 한다
- **B:** BebopNet은 실행 가능성만 문서로 조사한다. 다운로드는 사용자 승인이 필요하다
- **C(WJazzD 재학습)와 D(표현)는 보류한다**
- 완료 범위는 규칙으로 깨끗해진 MIDI가 아니다. 연주자 특징이 살아 있는 솔로다

## 구현
- `inference/control/realizer.py`
  - `abstract(line)`: 리듬, 쉼, 부호 있는 음정 윤곽, 프레이즈 끝
  - `realize`
    - 박 위·긴 음·프레이즈 끝은 윤곽 방향으로 가장 가까운 코드톤
    - 그 외는 스케일 음
    - 다음 앵커가 한 걸음 거리면 반음 접근음
    - 원 프레이즈가 반복할 때만 같은 음을 반복한다
    - 음역 C4–C6. 벗어나면 옥타브를 접는다
- 컴핑 `guide`(`comping.py guide_half`): 근음(C2–B2) + 3음·7음(A2–Ab3), 짧고 여리게. 2마디 고정 패턴이고 새 코드는 첫 박에 친다
- 런타임 선택지(초안): `--comp-style guide`, `--solo-floor`, `--clean-harmony`. 렌더 단계에서 반음/단9 충돌 컴핑 음을 제거한다
