## 질문

- 런타임은 쌍 S 설정이다(`--adapter-control`이 붙지만 PC가 없으므로 Tatum 완성만 연주한다). `--half-bar-blocks`, 128 BPM, 16마디, seed 42/43/44

- 비교 기준: 같은 seed의 무입력 반 마디 블록 실행(`outputs/half_bar/sweep/tatum_final/bpm128_seed*`, #1532)

## 판정 (모두 충족하면 "음 입력 경로 동작"으로 기록)
1. 3회 모두 완주, fallback 0, 미스 0
2. 입력 스냅샷에 음이 없는 블록은 무입력 실행의 같은 반 마디와 전부 동일하다(시드 결정성)
3. 음이 들어간 블록 중 적어도 하나는 무입력 실행과 다르다(입력이 실제로 primer에 쓰임). 세 실행 모두에서 확인한다
