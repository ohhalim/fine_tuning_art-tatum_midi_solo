# 반복 음 가중 학습 파일럿 — 모델이 앞 패턴을 다시 쓰게 되는가 (사전 등록)

작성 2026-10-02. 이슈 #1602. 판정 규칙은 학습 전에 고정했다. 독립 리뷰(Astra)는 사용자 지시로 나중에 일괄로 받는다. `musical_quality_verified: false` · `style_verified: false`.

## 근거와 한계
- #1597: 가능도로 보면 모델은 그 곡의 앞 문맥을 쓴다(M − N > 0). 그런데 자유 생성은 자연 문맥에서도 음정 재등장 IR 0.007이다(실제 0.052)
- #1600: temperature를 0.6까지 낮춰도 IR은 0.017에 그친다. 실제 연주의 2초 안 반복률은 0.073인데, 모델은 0.010 이하다
- 남은 후보는 모델의 생성 성향이다
- 이 두 진단은 학습 부족을 **판정하지 않았다**. 그래서 이 파일럿은 "학습으로 고칠 수 있는가"를 작게 시험하는 것이지, 앞 진단이 학습을 승인했다는 뜻이 아니다
- 기존 학습도 이미 연속 구간(다음 토큰 예측)이다. 이번 변경은 **손실 가중치 하나**뿐이다
  - 실제 연주에서 앞 8초 안의 윗선율 음정 3-gram을 다시 완성하는 note_on 토큰에 가중치 W를 준다. 나머지 토큰은 1이다

## 질문 (하나)
그 note_on 토큰에 손실 가중치를 더 주면, 같은 레시피의 무가중 학습보다 자유 생성의 음정 재등장이 늘어나는가. 처음 보는 곡의 가능도는 크게 나빠지지 않아야 한다.

## 고정 설계
- 출발점: 공통 base(`outputs/tvm/common_base/checkpoint_epoch8.pt`). 완성 Tatum과 같다
- 레시피(완성 Tatum과 동일, `scripts/run_mehldau_update_budget_diag.py --mode budget`)
  - 데이터 `data/tvm/tatum98`(학습 98곡, 선택셋 val12)
  - LoRA out_proj + QKV r16, lr 3e-4, batch 4, accumulation 4, cosine
  - 74 epoch(518 update), LS 0.1, seed 42, MPS
- 갈래
  - **A**: W = 1(무가중. 완성 Tatum의 재학습 대조)
  - **B**: W = 3
  - 두 갈래는 같은 seed와 같은 데이터 순서를 쓴다
- 가중 표시(`scripts/repeat_weights.py`)
  - 학습 crop 안에서 시각과 note_on 위치를 따라가며 윗선율(50 ms 묶음 최고음)을 만든다
  - 4음 창의 음정 3-gram이 그 창 시작 전 8초 안의 겹치지 않는 창에서 나온 적이 있으면, 4번째 음의 note_on 토큰을 표시한다
  - 같은 음 반복(음정 0,0,0)은 표시하지 않는다
  - 가중 손실: 토큰별 label smoothing CE에 가중치를 곱해 더하고, 가중치 합으로 나눈다(PAD 제외)
- 스냅샷 선택은 하지 않는다. 두 갈래 모두 마지막 518 update를 쓴다. val12로 고르지 않는다

## 판정 (모두 충족하면 통과, 학습 전 고정)
1. T 1.0에서 IR(B) − IR(A)의 곡 bootstrap 95% CI 하한 > 0이고, IR(B) ≥ 2 × IR(A)
2. fresh12 CE(B) − CE(A) ≤ +0.02
3. 보호 조건(B, T 1.0)
   - 반복률 ≤ 실제 반복률 + 0.15
   - 복사 비율 ≤ max(0.25, 실제 × 2)
   - 유효율 ≥ 0.9
