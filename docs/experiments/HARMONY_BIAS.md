# 화성 avoid 음 소프트 벌점 (사전 등록)

작성 2026-10-03. 이슈 #1656. 아스트라는 사용량이 끝나서 Claude 혼자 진행한다. 판정 규칙은 실행 전에 고정했다. `musical_quality_verified: false`.

## 근거
- 사용자 청취(G1/G2, 이어 치기 버전): "조금 나아졌는데 그래도 불협이 많아"
- 진단(`outputs/combined_check` 6회, 태깅된 솔로, 탐색)
  - 솔로 시간 중 코드의 avoid 음: **16.1%**
  - 동시에 울리는 컴핑 음과 반음·장7도·단9도 관계인 솔로 시간: **12.2%**
  - 박 위 솔로 음 중 avoid 음: 13.9%
  - 도수별 솔로 시간: 11도(예: C·C7 위 F)가 10%, b3가 9%
- 지금 쓰는 박 위 clash 지표(.28)는 들린 불협의 일부만 본다
- 모델은 코드에 약하게 반응한다(#1636)

## 변경 (opt-in, 기본 끔)
- `--harmony-bias S`: 반마디 블록마다 그 코드의 avoid pc에 해당하는 note_on logit에서 S를 뺀다
  - grammar mask 뒤에 적용한다. 금지가 아니라 확률을 낮춘다(S = 2.0이면 약 0.135배)
  - 반음 경과음과 접근음은 여전히 나올 수 있다
- avoid 집합(근음 기준, 일반적인 코드 스케일 관행)
  - maj7: b9 b3 11 b13 b7(#11 허용)
  - 7: 11 7(b9 #9 #11 b13 텐션 허용)
  - m7: b9 3 #11 b13 7
  - m7b5: b9 3 5 13 7
  - dim: b9 3 5 b7
- **S = 2.0으로 고정한다.** 결과를 보고 다시 고르지 않는다
- `--pattern-cache`와 함께 쓸 수 없다(logits processor가 하나뿐이다)

## 실행
- 청취 설정 전체(COMBINED_CHECK)에 팔 두 개를 같은 seed로 교대 실행한다: bias0 / bias2
- holdout 진행 3개 × seed 42·43, 16마디, 128 BPM
- `scripts/dissonance_check.py`. 집합과 설정을 검증한다

## 판정 (실행 전 고정, bias2 기준)
1. avoid 음 솔로 시간 비율 ≤ bias0의 0.5배
2. 컴핑과 동시 충돌하는 솔로 시간 비율 ≤ bias0의 0.7배
3. 박 위 clash ≤ bias0 + 0.01
4. 경계 연결: ≥ 9 비율 ≤ 0.22, p50 ≤ 4
5. 다양성 유지(교본처럼 단조로워지는지 보는 proxy): 시작 음정 고유 비율 ≥ bias0의 0.9배, 같은 음 반복 ≤ bias0 + 0.05, 복사 블록 ≤ 0.05
6. 초당 음 수가 데이터의 0.67–1.5배, 쉼 ≥ 0.5배
7. 대체 패턴 0, miss ≤ 2, invalid 0, block-ready p99 ≤ 419 ms. 앞선 결합 검사에서 여유가 11 ms뿐이었으므로 가장 걸리기 쉬운 조건이다
- 미달이면 기록하고 S를 다시 고르지 않는다. 판정 7만 걸리면 `--candidates 1`과 결합한 설정을 따로 등록할 수 있다(이번에는 하지 않는다)
- 통과해도 "불협이 줄어 듣기 좋다"는 인증이 아니다. 청취로 확인한다
