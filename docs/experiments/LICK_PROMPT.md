## 6. 판정 (실행 전 고정)

- 선호 프롬프트마다 P0 대비 1차 지표의 중앙값 차이: bootstrap 95% CI(10,000회, seed 0), 양측 순열 검정 p(10,000회)
- 유의 수준 0.05 / 9(프롬프트 3 × 1차 지표 3, Bonferroni) ≈ 0.0056, 최소 효과 M1 2.0회/분, M2 1.0음/초, M3 0.15
- 판정: M1 또는 M3가 유의하고 최소 효과 이상 증가 → 가까워짐. 유의하게 감소 → 멀어짐. 둘 다 → 섞임. 그 외 → 이 n에서 차이 미검출. M2는 방향(7.86과의 거리)과 검정만 기록
- 복사 지표가 프롬프트 릭 길이에 가까우면(최장 공통 8 이상) 그 프롬프트 결과는 "복사 섞임"으로 표시
- 측정 특성이 가까워져도 음악적으로 원하는 릭이라는 뜻 아님. 사용자 청취로 판단
