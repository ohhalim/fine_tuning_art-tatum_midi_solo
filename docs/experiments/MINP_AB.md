# min_p 필터 제거 A/B: 반복이 줄어드는가 (사전 등록)

작성 2026-10-08. 선행: `LOOP_DIAG.md`, `LOOP_TF.md`. 아스트라 #199 설계. 새 학습 없음. `musical_quality_verified: false`.

## 질문 (하나)
Aria 샘플링에서 min_p를 0.035에서 0으로 바꾸면, 실제 생성의 지속 반복이 줄고 다른 실패가 늘지 않는가.

- 가설: min_p 필터가 확률 낮은 "탈출" 후보를 지워서 반복을 굳힌다
- LOOP_TF가 이 가설을 입증한 것은 아니다. 별개 가설이다

## 고정 조건
- Aria 커밋 `c2f67bc90b49335543c0249fe00fb84a9337faf8` + `max_kv_pos` 로컬 패치(logits 동일 확인). 가중치 `model-gen.safetensors`(sha256 앞 16자리 `5e6b07ee2680f004`)
- 프라이머: 기존 5개 전부(P1 pokey_jazz, P2 Joy Spring, P3 Bud-Like, TA, TB), 각 8초
- temp 0.98, 생성 길이 상한 1024토큰(안전 상한), 배치 1
- **A:** min_p 0.035(지금 설정). **B:** min_p 0
  - 코드 확인: `sample_min_p`는 `probs >= min_p × p_max`만 남기고 다시 정규화한다. 0이면 아무것도 지우지 않는 순수 온도 샘플링이다. 우회 구현은 필요 없다
- **seed:** 프라이머마다 1과 2(생성 전 고정). 실제 난수는 MLX가 아니라 `torch.multinomial`(CPU)이므로 매 생성 직전에 `torch.manual_seed(seed)`를 건다. 같은 seed라도 A와 B는 분포가 달라서 같은 음악이 나오지 않는다. 같은 조건을 다시 돌리면 같은 토큰이 나오는지는 smoke로 확인한다
- 총 20개(5 × 2 × 2)를 전부 보고한다
- 기존 T3·T3c 출력 10개는 새 A의 대체 대조로 쓰지 않는다

## 저장 (manifest)
- 샘플링된 원 토큰, 정지 원인(EOS 또는 길이 상한), 모델·패치·해시·seed·실행 조건, 출력 MIDI
- 같은 렌더러로 만든 오디오 20개를 보존한다. 듣기 전에 좋은 샘플을 골라내지 않는다

## 측정 (생성 시작 후 첫 16초)
- 생성 시작: 프라이머 토큰 음을 (pitch, onset) 다중집합으로 지운 뒤 첫 생성 음의 onset
- **반복 점유 시간:** 음높이 집합열 반복(LOOP_DIAG 정의: 30 ms 묶음, 주기 ≤ 24 이벤트, 3회 이상)이 2초 이상 이어진 구간들의 합집합 길이 / 16초
- **4초 이상 루프:** LOOP_DIAG 정의의 루프(≥ 3회, ≥ 4초)가 16초 안에 있는가
- **음역 붕괴:** 2초 창 안의 음이 6개 이상이고 모두 C3(48) 아래인 창이 있는가
- 따로 보고: 리듬(이벤트 간격 중앙값), velocity 범위
- **coverage:** 생성 부분이 16초에 못 미치면 제외하지 않고 "coverage 실패"로 따로 센다. 정지 원인과 함께 적는다

## 완료 판정 (결과 전 고정)
- 표로 보고한다: (프라이머, seed) 10쌍마다 A와 B의 반복 점유, 4초 루프 여부, 음역 붕괴, coverage, 정지 원인
- 확인할 것: 기술적 유효성(오류 없이 생성)과 coverage가 B에서 나빠지지 않은 채로, 반복 감소 방향(B 점유 < A 점유)이 seed 1·2 양쪽과 여러 프라이머에서 나타나는가
- 10쌍 소표본이다. 통계적 우월이나 품질 성공을 주장하지 않는다. 기본값을 바꾸지 않는다
- 음 종류(다양성)가 늘어난 것만으로 성공이라 하지 않는다. 무작위화일 수 있다
- 반복 감소가 없거나 다른 결함이 늘면 이 가설을 기각 또는 유보하고, sweep을 넓히지 않고 끝낸다

### 판정 (사전 등록 범위)
- 사전 등록한 확인 사항은 충족됐다. B에서 기술적 유효성과 coverage가 나빠지지 않았고, 반복 감소 방향이 seed 양쪽과 여러 프라이머에서 나타났다
- 10쌍 소표본이다. 통계적 우월이나 품질 성공을 주장하지 않는다. 기본값을 바꾸지 않는다
- 음악적으로 더 나빠졌는지(필터 없이 꼬리 확률의 음을 뽑아 엉뚱한 음이 늘었는지)는 이 지표로 알 수 없다. 청취로 확인한다
- 이 결과는 "min_p 필터가 반복을 굳힌다"는 가설과 맞는 관찰이지 인과 증명이 아니다. 필터를 없애면 분포 전체가 바뀐다
