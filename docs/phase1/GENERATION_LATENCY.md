# Phase 1 — 생성 구간 지연 측정

측정일 2026-09-20. 이 문서는 **생성 구간만** 다룬다.
Phase 1 게이트인 왕복 지연(키보드 → 모델 → DAW)은 **아직 측정하지 않았다.**
구간별 예산은 [LATENCY_BUDGET.md](LATENCY_BUDGET.md) 참고.

`quality_claimed: false` — 여기 있는 수치는 전부 능력(capability) 측정이고
음악적 품질 주장이 아니다.

## 조건

| | |
|---|---|
| 모델 | Music Transformer 13.7M, LoRA `armD_lora/ckpt/checkpoint_epoch8.pt` |
| 하네스 | `scripts/run_jazz_mvp.py`, 마디별 독립 생성, 고정 primer |
| 설정 | 128 BPM(마디 1875ms), 8마디 × seed 42/100/200/300 = 32마디 |
| 토큰 예산 | `target_length=80` |
| 기기 | Apple Silicon, PyTorch MPS / CPU |

## 결과

| | 중앙 | p90 | 최대 | 마디 초과 | ms/토큰 | 예산 80 추정 |
|---|---|---|---|---|---|---|
| **MPS** | 335ms | 791ms | 2237ms | **1/32** | 32.5 | 2576ms (**137%**) |
| **CPU** | **58ms** | 289ms | 545ms | 0/32 | 10.9 | **859ms (46%)** |

`예산 80 추정`은 선형 적합 `지연 = 절편 + 기울기 × 토큰` 에 토큰 예산 80을 넣은 값이다.

## 판단

1. **지연은 방출 토큰 수에 선형이다** (MPS r=+0.93, n=32).
   자기회귀 생성이므로 당연하지만, 측정해 두면 지연 예산을 토큰 예산으로
   직접 환산할 수 있다. 그래서 `report.json` 의 마디별 `generation` 에
   `model_forward_step_count` 를 기록한다.

2. **MPS 에서는 현재 토큰 예산이 실시간 예산을 만족하지 못한다.**
   80 토큰을 다 쓰면 마디의 137%. 실제로 32마디 중 1회 마디를 넘었다.

3. **CPU 로 바꾸면 통과한다.** `FORCE_CPU=1` 환경변수가 이미 있다.
   13.7M 모델에서는 GPU 커널 디스패치 오버헤드가 연산량보다 크다.
   중앙 58ms 는 jam_bot 이 보고한 반주 목표 100ms 안에 들어온다.

## 기각한 가설 — KV 캐시

`music_transformer.py:57` 은 매 토큰마다 `self.forward(gen_seq[..., :cur_i])`
로 **전체 시퀀스를 재처리한다.** KV 캐시가 없다. jam_bot 논문도 KV 캐싱을
필수 최적화로 든다. 그래서 이게 병목이라고 보고 구현하려 했다.

**측정 결과 틀렸다.** 단일 forward 비용이 시퀀스 길이에 평평하다:

| 시퀀스 길이 | 8 | 16 | 32 | 48 | 64 | 80 |
|---|---|---|---|---|---|---|
| forward (MPS) | 18.5ms | 16.2ms | 19.8ms | 16.9ms | 20.7ms | 17.4ms |

우리 시퀀스 길이(32~80)에서는 O(n²) 항이 고정 호출 오버헤드에 묻힌다.
KV 캐시를 넣었어도 이득이 거의 없었을 것이다. 더 긴 컨텍스트로 가면
다시 검토해야 한다.

단일 forward(48 토큰) 비교: MPS 18.6ms vs **CPU 9.2ms (2.03배)**.

## 남은 것

- **왕복 지연 미측정.** 이 문서는 생성 구간뿐이다. MIDI 입력 수신,
  스케줄러 디스패치, 포트 전송, DAW 수신이 빠져 있다.
- **기기 간 재현성 없음.** CPU/MPS 부동소수점 차이로 샘플링이 갈린다
  (같은 seed 에서 model 마디 CPU 28/32 vs MPS 29/32). seed 재현성은
  기기 고정 조건에서만 성립한다.
- **연속 루프 미검증.** 마디별 독립 생성을 일괄 실행한 값이라, 롤링
  루프에서 생성과 재생이 겹칠 때의 경합은 반영돼 있지 않다.
